# Provenance

Copied verbatim from the Movie Recommender repository
(https://github.com/Shaurya6355/movielens-recommender), commit 06fde5b:

- `evaluation.json` ← `reports/results/evaluation.json` (test-window metrics, bootstrap CIs)
- `latency.json`    ← `reports/results/latency.json` (serving benchmark)
- `sweep.json`      ← `artifacts/sweep.json` (27-run ALS tuning grid, validation window;
  generated locally by `make tune` — artifacts/ is not committed to that repo)

The case study and figures read these files directly; do not edit the numbers by hand.
If the experiment is re-run, copy the new files over and rebuild.
- `split_manifest.json` ← `data/processed/split_manifest.json` (temporal split cutoffs and row counts; generated by `make splits`)
